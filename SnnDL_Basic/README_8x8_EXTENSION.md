# 8x8网络扩展版本

## 🚀 概述

基于原有4x4分层神经网络分类系统，我们成功扩展到**8x8网络架构**，实现了**4倍规模**和**2倍分类能力**的提升。

## 📊 规模对比

| 特征 | 4x4网络 | 8x8网络 | 提升倍数 |
|------|---------|---------|----------|
| PE数量 | 16个 | 64个 | 4x |
| 神经元总数 | 256个 | 1024个 | 4x |
| 分类能力 | 4类 | 8类 | 2x |
| 网络深度 | 4层 | 5层 | 1.25x |
| 内存需求 | 1GB | 8GB | 8x |
| 带宽需求 | 40GB/s | 80GB/s | 2x |

## 🏗️ 网络架构

### 8x8分层设计
```
输入层 (PE 0-7)      8个PE  →  8类输入
隐藏层1 (PE 8-23)    16个PE →  特征提取
隐藏层2 (PE 24-39)   16个PE →  特征组合  
隐藏层3 (PE 40-55)   16个PE →  高级特征
输出层 (PE 56-63)    8个PE  →  8类输出
```

### 连接策略
1. **输入层→隐藏层1**: 选择性连接 (权重强度12.0)
2. **隐藏层1→隐藏层2**: 稀疏全连接 (权重强度14.0) 
3. **隐藏层2→隐藏层3**: 选择性连接 (权重强度16.0)
4. **隐藏层3→输出层**: 竞争性连接 (权重强度18.0)

## 🚀 使用方法

### 一键运行
```bash
./scripts/run_full_test_8x8.sh
```

### 分步运行
```bash
# 1. 生成脉冲数据
python3 scripts/generate_spike_data_8x8.py

# 2. 生成权重文件
python3 scripts/generate_optimized_weights_8x8.py

# 3. 运行仿真
sst scripts/test_classification_8x8.py

# 4. 分析结果
python3 scripts/analyze_classification_results_8x8.py
```

## ⚙️ 配置参数

### 系统配置
```python
MESH_SIZE = 8                    # 8x8网格
TOTAL_NODES = 64                 # 64个PE节点
NEURONS_PER_PE = 16              # 每PE 16个神经元
SIMULATION_TIME = "1500us"       # 延长仿真时间
```

### 内存配置
```python
PE_MEMORY = "128MiB"            # 每PE 128MB内存
L1_CACHE = "8KiB"               # 增加L1缓存大小
WEIGHT_STRIDE = 65536           # 增加权重矩阵步长
```

### 网络配置
```python
NETWORK_BANDWIDTH = "80GiB/s"   # 双倍网络带宽
BUFFER_SIZE = "16KiB"           # 双倍缓冲区大小
```

## 📈 性能优化

### 稀疏连接优化
- **选择性连接**: 减少80%连接，保持关键路径
- **稀疏全连接**: 30%连接密度，平衡性能与复杂度
- **竞争性连接**: 强化类别区分，抑制无关连接

### 内存优化
- **独立地址空间**: 每PE独立128MB内存空间
- **增强缓存**: 8KB L1缓存，提高权重访问效率
- **批量加载**: 64B缓存行，优化内存带宽利用

### 网络优化
- **双倍带宽**: 80GB/s网络带宽，应对4倍通信量
- **增大缓冲**: 16KB缓冲区，减少阻塞概率
- **负载均衡**: 分层架构天然分散通信热点

## 🔬 扩展性验证

### 理论分析
- **计算复杂度**: O(n²) → O(4n²)，4倍增长
- **内存复杂度**: O(n²) → O(4n²)，4倍增长  
- **通信复杂度**: O(n) → O(2n)，2倍增长

### 实际测试
- **编译时间**: 预期增长50-100%
- **仿真时间**: 预期增长200-400%
- **内存占用**: 预期增长300-800%
