
## 🧠 神经元模型

### LIF (Leaky Integrate-and-Fire) 模型
- **膜电位方程**: τ_mem * dV/dt = -(V - V_rest) + I_input
- **发放条件**: V ≥ V_thresh
- **重置机制**: V = V_reset (发放后)
- **不应期**: t_ref = 2ms

### 关键参数
| 层级 | V_thresh | τ_mem | t_ref |
|------|----------|-------|-------|
| 输入层 | 0.02 | 20ms | 2ms |
| 隐藏层1 | 0.02 | 20ms | 2ms |
| 隐藏层2 | 0.02 | 20ms | 2ms |
| 输出层 | 0.025 | 20ms | 2ms |

## 🔗 连接策略

### 1. 选择性连接 (输入→隐藏层)
```python
# 主要连接 (强权重)
primary_weight = base_strength * (1.2 ~ 1.8)

# 次要连接 (弱权重)  
secondary_weight = base_strength * 0.6 * (0.8 ~ 1.2)
```

**映射规则**:
- PE4 主连 PE0, 次连 PE1,2,3
- PE5 主连 PE1, 次连 PE0,2,3
- PE6 主连 PE2, 次连 PE0,1,3
- PE7 主连 PE3, 次连 PE0,1,2

### 2. 竞争性连接 (隐藏层2→输出层)
```python
# 同类别连接 (强权重)
same_class_weight = base_strength * 2.0 * (0.9 ~ 1.1)

# 异类别连接 (抑制权重)
diff_class_weight = base_strength * 0.2 * (0.9 ~ 1.1)
```

**分类映射**:
- PE12 强连 PE8 (类别A路径)
- PE13 强连 PE9 (类别B路径)
- PE14 强连 PE10 (类别C路径)
- PE15 强连 PE11 (类别D路径)

## 📊 权重矩阵结构

### 权重存储格式
- **文件格式**: 二进制float32
- **矩阵维度**: 16 × (16×16) = 16 × 256
- **存储布局**: 行优先(Row-major)
- **索引计算**: `weight_index = target_neuron * 256 + source_neuron`

### 权重分布
| 层级 | 非零权重比例 | 权重范围 | 平均权重 |
|------|-------------|----------|----------|
| 输入层 | 6.2% | 0.0 ~ 0.5 | 0.014 |
| 隐藏层1 | 25.0% | 0.0 ~ 18.0 | 2.1 |
| 隐藏层2 | 25.0% | 0.0 ~ 22.0 | 2.5 |

## 🔧 内存系统架构

### 分层存储
```
SnnPE ←→ L1 Cache ←→ Memory Bus ←→ Memory Controller ←→ WeightLoader
```

### 缓存配置
- **L1缓存大小**: 4KB
- **缓存行大小**: 64B
- **关联度**: 4-way
- **访问延迟**: 2 cycles @ 2GHz

### 内存配置
- **每PE内存**: 64MB独立地址空间
- **内存后端**: SimpleMem
- **访问延迟**: 100ns
- **带宽**: 不限制

## 📡 网络通信

### Merlin网络配置
- **拓扑**: 4×4 2D Mesh
- **路由算法**: HR Router
- **虚拟网络**: 1个
- **带宽**: 40GB/s
- **仲裁**: LRU

### 包格式
- **Flit大小**: 8B
- **缓冲区大小**: 4KB (输入/输出)
- **延迟**: 10ns (输入/输出)

## ⚡ 性能优化策略

### 1. 权重缓存机制
- **缓存策略**: LRU替换
- **命中率优化**: 预热100周期
- **回退机制**: 事件权重1.0

### 2. 内存访问优化
- **批量读取**: 64B缓存行
- **并发请求**: 16个outstanding请求
- **地址对齐**: 权重矩阵按行对齐

### 3. 网络通信优化
- **包合并**: 相同目标节点包合并
- **流量控制**: 基于缓冲区占用
- **负载均衡**: 多路径路由
