# SnnDL v5 P4 Merlin Unicast Sign-off

## Decision

P4 is accepted. SnnDL v5 now closes the minimum credible 2D cycle model from
remote spike injection through SST Merlin, the bounded PE endpoint, SnnCoreV5,
typed Core SRAM, DMA-preloaded weight SPM, private L1, shared PE L2, and the
chip DRAM controller. Performance run class and claim level T are enabled for
this boundary.

## Implemented Boundary

- `NocPacketV5Event` provides a versioned 48-byte header and includes timestep,
  source/destination PE/Core, neuron identities, sequence, payload size, and
  injection time.
- `PeEndpointV5` owns finite TX/RX queues, checks `spaceToSend()` before every
  send, retains RX data in LinkControl when local capacity is full, retries Core
  ingress, and reports zero-drop conservation evidence.
- `merlin.linkcontrol`, `merlin.hr_router`, and `merlin.mesh` own flit
  serialization, credits, routing, link bandwidth, crossbar arbitration, and
  router queues. SnnDL does not implement a parallel router.
- The local SST 15 mesh requires two router-internal VN/VC indices for a turning
  path. Endpoints inject only data VN 0; P5 still owns timed control traffic.

## Acceptance Evidence

Authoritative result:
`snndl_runs/p4_v5_acceptance_20260805/acceptance.json` (`PASS`).

The suite covers zero/one/straight/turning hop latency, 1/2/4-flit stream
serialization, independent link and crossbar sensitivity, 4x4 and 8x8
all-to-one pressure with small buffers, and an integrated remote Core/memory
fixture. The 4x4 and 8x8 pressure cases delivered 120 and 252 logical packets
with 24,874,125 and 183,142,874 accumulated Merlin stall samples respectively;
all endpoint queues drained and `drops=0`. The integrated destination accepted
one remote spike, performed two timed weight reads, issued and retired two
synapses, and preserved preload-before-Start.

P3.5 was rerun in full at
`snndl_runs/p4_v5_acceptance_20260805/regression_p35/acceptance.json` and passed
for SimpleMem, Ramulator2, 2 PE x 2 Core, queued rows, and earlier P1/P3 guards.

## Claim Boundary

P4 supports deterministic 2D unicast and source replication. Router-native
multicast and timed chip-wide synchronization are not part of this result and
remain P5.
