## Review Checklist

1. **Independent ELI component: PASS.** `SnnDL.SnnCoreV5` owns clock,
   lifecycle, ports, bounded pipeline state, and statistics. The ideal
   provider is `SnnDL.IdealSynapseSource`; neither depends on GAS, 3D, legacy
   workload, local-storage, cache, or DRAM code.
2. **Cycle semantics: PASS.** Each tick completes ready work before issuing
   new work; each stage has finite width and queues; no callback drains a stage
   without a width bound. Zero latency still crosses a clock boundary.
3. **Backpressure: PASS.** Spike ingress uses explicit accepted/retry ACKs.
   Row responses and row-done messages use per-item provider ACKs. Queue-full
   events retry without drop or fatal termination.
4. **Determinism: PASS.** Responses may arrive in reverse order while the
   deterministic retire key `(post_neuron, source_event_seq, edge_ordinal)`
   preserves the functional digest.
5. **Statistics: PASS.** Evidence exposes per-stage accepted/issued/completed,
   maximum occupancy, busy cycles, full cycles, and stall cycles, plus core
   elapsed cycles. The ELI registration publishes all declared P1 full/stall
   counters instead of fixed zero placeholders.
6. **Scale and isolation: PASS.** C++ tests cover width 1/2/4, queue pressure,
   64/256/1024 neuron scans, independent 1/2/4/8 Core instances, response
   reordering, and unrelated-stage latency isolation. SST tests cover minimal,
   reverse, queue-one ingress retry, provider retry, and three neuron scales.
